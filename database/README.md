# Banco de Dados

Esta pasta contém a documentação relacionada à modelagem e estrutura do banco de dados do projeto FeioDiesel.

## Diagramas

Os diagramas estão organizados na pasta `diagrams/`.

### Diagrama Simples

Representação inicial e simplificada das principais entidades e seus relacionamentos.

Arquivo editável:

`01-diagrama-simples.drawio`

Visualização:

`01-diagrama-simples.png`

### Diagrama Detalhado

Representação mais detalhada da estrutura do banco de dados, incluindo entidades e seus relacionamentos.

Arquivo editável:

`02-diagrama-detalhado.drawio`

### Diagrama ERD

Diagrama Entidade-Relacionamento utilizado para representar a estrutura lógica dos dados e seus relacionamentos.

Arquivo editável:

`03-ERD.drawio`

## Organização

```text
database/
├── diagrams/
│   ├── 01-diagrama-simples.drawio
│   ├── 01-diagrama-simples.png
│   ├── 02-diagrama-detalhado.drawio
│   └── 03-ERD.drawio
│
└── README.md
```

## Objetivo

A documentação do banco de dados tem como objetivo registrar a evolução da modelagem do sistema e servir como referência durante o desenvolvimento da aplicação.
